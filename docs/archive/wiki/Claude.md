## Required AI Data

**Each jurisdiction file must include:**
- **Contact routing**: Direct emails/phones for specific council members, department heads, key staff
- **Issue classification**: "Housing complaint" → Planning Dept vs Building Dept vs Code Enforcement
- **Decision timing**: "Planning applications take 60 days, budget items decided in May"
- **Meeting access**: When/where/how to participate
- **Success data**: Examples of what public input actually changed votes
