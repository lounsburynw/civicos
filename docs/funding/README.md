# Funding Strategy & Grant Tracker

*Created: Session 210 (December 2025)*
*Status: Active*

## Situation

- **Current status:** FTE at Genentech (Bay Area biotech), building Civic nights/weekends
- **Scope:** Single city pilot (San Rafael, CA) - not multi-city yet
- **Code status:** Private repository (GitHub public profile is minimal)
- **Goal:** Secure funding to run pilot, validate coordination hypothesis, then open-source
- **Timeline:** Pilot planned for Jan 2026 or shortly after
- **Initial ask range:** $10-25K (project funding, not salary replacement)

## Strategy

### Phase 1: Small Grants While Employed (Dec 2025 - Q1 2026)
- Target: $10-50K in project funding
- Use: Contractor hours, infrastructure, pilot costs
- Stay at Genentech during this phase
- Build track record with smaller grants

### Phase 2: Larger Grants Post-Pilot (Q2 2026+)
- Target: $50-150K depending on pilot results
- Decision point: Part-time transition or full-time leap
- Requires pilot case study and demonstrated impact

### Framing (for all applications)
> "I'm a senior technologist building civic coordination infrastructure on nights/weekends.
> I've proven the concept works (26 cities extracting events, $7/month operational cost).
> I'm seeking funding to accelerate development and validate the coordination hypothesis
> through a structured pilot before deciding whether to pursue this full-time."
